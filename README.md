# kp_industries_project

A modern, pixel-perfect, and fully responsive frontend redesign for **KP Industries** (Industrial Material Supplier, Waste Water Treatment & Plant Designing).

Live Website Demo: [Click Here to View Live](https://tanushriraut045-source.github.io/kp_industries_project/)

##Key Features

1.Mobile-First Responsive Design: Seamless layout scaling across Mobile, Tablet, Laptop, and Widescreen Desktop devices using custom Tailwind CSS breakpoints.
2.Hero Image Carousel: Dynamic auto-sliding banner showcasing industrial spark visuals, water purification, and treatment plants with clickable dot navigation.
3.Industrial Services Grid: Structured multi-column cards covering:
  - Water & Waste Water Treatment
  - Design & Consultation (Piping, Process & CAD)
  - Industrial Material Supply
  - Turnkey Plant Designing Services
4.ISO 9001:2015 Certification Showcase: Official DBS CERT certificate card with preview integration.
5.Location & Contact Integration: Embedded Google Maps navigation and direct WhatsApp click-to-chat action.
6.Inquiry Modal Form: Quick contact capture form for lead generation.

## 🛠️ Tech Stack

1.HTML5: Semantic markup structure
2.Tailwind CSS: Modern utility-first styling via CDN
3.JavaScript (ES6): Carousel slider logic, modals, and interactive UI handling
4.Google Fonts: Playfair Display (Serif) & Inter (Sans-serif)
5.Deployment: GitHub Pages (Automated CI/CD Workflow)
